# ❄️ منصة WINTER ARC — تتبع الـ 180 يوم (6 أشهر)

موقع وتطبيق ويب محلي وشخصي صُمم خصيصاً لـ **عمر**، ليعمل **100% بدون إنترنت (Offline)** طوال فترة الـ Winter Arc (6 أشهر متواصلة = 180 يوماً).

---

## 🚀 طريقة التشغيل فوراً
1. توجه لمجلد `D:\عمر`.
2. اضغط مرتين (Double Click) على ملف **`index.html`**.
3. سيفتح الموقع مباشرة في متصفحك المفضل (Google Chrome, Microsoft Edge, Brave, Firefox) **بدون الحاجة لأي اتصال بالإنترنت أو تثبيت برامج**.

## 🌟 أبرز المميزات والإمكانيات

### 1. صفحة اليوميات وجدول الالتزام اليومي (مطابقة لدفترك الواقعي)
- **الصلوات الخمس**: تتبع الفجر، الظهر، العصر، المغرب، والعشاء بأزرار تفاعلية مضيئة.
- **القرآن الكريم**: تسجيل قراءة الورد اليومي مع خانة مخصصة لتدوين عدد الصفحات وتدبر الآيات.
- **الابتعاد عن الذنوب وضبط النفس**: خياران للالتزام والثبات أو الاعتراف والنهوض الفوري.
- **عادات الـ Winter Arc اليومية**:
  - تمرين رياضي / جيم (Workout)
  - العمل المركز على هدفي (Deep Work)
  - قراءة وتغذية العقل
  - شرب 3 لتر مياه + دايت نظيف
  - نوم واستيقاظ منضبط
  - **إمكانية إضافة وحذف أي عادة مخصصة بنقرة واحدة!**
- **تقييم اليوم ومؤشر الرضا**: تقييم رقمي من 1 إلى 10، تحديد مستوى الرضا عن اليوم، وحالة الطقس النفسي مع مقولة: *"مش مهم النتيجة بقدر السعي وثبات الخطى"*.
- **التدوين ومحاسبة النفس الصادقة (4 أسئلة جوهرية)**:
  1. *أنا النهارده...* (وصف دقيق للأحداث ومن كان معك وما دفعك للاستمرار).
  2. *إيه اللي عملته النهارده وقرّبني من هدفي؟ وإيه اللي عطلني؟*
  3. *إيه إحساسي وأنا ماشي في الطريق؟*
  4. *احكي لنفسك بصدق... إيه اللي جواك النهارده؟*

### 2. صفحة الـ 180 يوم ومربعات التقدم السائلة (Liquid Fill Matrix)
- شبكة تفاعلية تضم **180 مربعاً** تمثل الـ 6 أشهر يوماً بيوم.
- **تعبئة المربع بالنسبة الفعلية بدقة**: إذا أنجزت 70% من مهام يومك، يمتلئ المربع رأسياً بنسبة 70% بسائل أزرق جليدي مع كتابة 70% وتوهج نيوني.
- تدرج لوني حسب الالتزام:
  - 0%: هادئ ومظلم.
  - 1% - 49%: أزرق كحلي.
  - 50% - 79%: أزرق سماوي مشرق.
  - 80% - 99%: تركواز ثلجي متوهج.
  - 100%: **توهج ذهبي أسطوري (Golden Aura) مع انطلاق ألعاب نارية واحتفال بصري!**
- **مربعات تفاعلية**: عند الوقوف بالماوس يظهر كرت عائم يعرض ملخص اليوم، وعند النقر على أي مربع ينقلك فوراً لتعديل ذلك اليوم.
- **فلترة بالأشهر**: تصفح الشهر 1 أو 2 أو 3 أو الـ 180 يوم دفعة واحدة.

### 3. حفظ البيانات بنسبة 100% محلياً (Zero Data Loss)
- **حفظ تلقائي فوري (Auto-save)**: بمجرد كتابة أي كلمة أو الضغط على أي مهمة يتم حفظها لحظياً داخل المتصفح `localStorage`.
- **تصدير واسترجاع النسخ الاحتياطية (Export / Import JSON)**: زر في الإعدادات لتحميل ملف نسخة احتياطية على جهازك في ثانية واحدة لضمان أمان كل تدويناتك.
- **طباعة اليوم**: زر مخصص لتحويل يومك إلى PDF أو طباعته بتنسيق ورقي نظيف.

### 4. لمسات بصرية وصوتية Winter Arc
- تصميم Dark Glassmorphism فخم بظلال Midnight Cyan و Icy Frost.
- مؤثرات صوتية تكتيكية للنقر والتسجيل (Web Audio API) بدون أي ملفات خارجية.
- تساقط ثلوج خفيف هادئ في الخلفية يمنح أجواء الـ Winter Arc (يمكن تشغيله أو إيقافه بزر علوي).
