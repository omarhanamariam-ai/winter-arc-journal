# 07. خطة التطوير البرمجي لموقع WINTER ARC (Website Development Plan)

## ١. الفحص المعماري لملفات الموقع الحالي (Codebase Audit - `d:\عمر`)

تم إجراء تدقيق برمجي شامل لملفات المشروع الموجودة في مسار العمل:
* **`index.html`** (1,106 أسطر): واجهة مستخدم مبنية بـ HTML5 دلالية، تدعم اتجاه اليمين لليسار (`dir="rtl"`) للغة العربية بالكامل، مع بنية تبويبات واضحة عبر عناصر `<main class="view-container">`.
* **`style.css`** (3,417 سطراً): نظام تصميم متكامل فائق الاحترافية يعتمد على نمط الـ **Obsidian Frost / Midnight Cyan Glassmorphism**، مع متغيرات جذرية (`:root`) للألوان والتوهجات والانتقالات، واستجابة كاملة للشاشات الصغيرة (Mobile Responsive).
* **`app.js`** (2,304 أسطر): جافاسكريبت نقية (Pure Vanilla JS) تعمل بنظام الكبسولة الذاتية `(function() { 'use strict'; ... })();`.
* **`sw.js` و `manifest.json`**: تطبيق ويب تقدمي (PWA) يعمل **بنسبة 100% بدون إنترنت (Offline-First)** مع كاش محلي كامل.
* **الأداء والاعتمادات:** **صفر اعتمادات خارجية (Zero External CDN Dependencies)**، ومحرك صوتيات داخلي يولد النغمات برمجياً عبر `Web Audio API`، ومحركان للكانفاس لتساقط الثلج واحتفالات النصر.

```
        القيمة للمستخدم (User Value)

    متوسطة    │
```

### المرحلة الأولى: المنتج الأدنى القابل للتطبيق (MVP - Phase 1)
1. **لوحة الأهداف والمؤشرات (Goal & Density Dashboard):**
   * عرض الوزن الحالي (60 كجم) مقابل الهدف المرحلي الأول (70 كجم) والهدف النهائي (80 كجم).
   * مؤشر الكثافة الكتلية الخطية الحية ($\text{kg/m}$) ومعدل التقدم نحو الكثافة الحجرية ($> 40 \text{ kg/m}$).
2. **حاسبة الحصص المصرية بدون ميزان (No-Scale Portion Tracker):**
   * بطاقات تفاعلية بنقرة واحدة: `[+ رغيف بلدي]`، `[+ كوباية رز]`، `[+ كوباية لبن]`، `[+ كف كبدة/بروتين]`، `[+ معلقة سوداني]`، `[+ ثمرة بطاطا]`.
   * عدادات لحظية للسعرات نحو الـ 2,850 كالوري والبروتين نحو الـ 135 جم مع صوت النقر `sound.playTick()`.
3. **مخطط الوزن الأسبوعي التفاعلي (Weekly Weight Trendline):**
   * رسم بياني خفيف الوزن مرسوم بـ HTML5 Canvas بدون مكتبات خارجية، يقارن المسار المستهدف بالوزن الفعلي ويطبق شجرة القرار الأسبوعية أوتوماتيكياً.

### المرحلة الثانية: سجل الأحمال والزيادة التدريجية (Phase 2)
1. **سجل جلسات التدريب الأسبوعية (Workout Logger):**
   * واجهة تفاعلية لعرض تمارين اليوم (Upper A / Lower A / Upper B / Lower B) وإدخال الوزن والتكرارات لكل مجموعة.
2. **كاشف الأرقام القياسية الذكي (Auto-PR Detector):**
   * مقارنة أوزان اليوم مع آخر جلسة مسجلة في الذاكرة لنفس التمرين؛ عند تحطيم رقم قياسي، يتم إطلاق شارة `🔥 NEW PR!` مع صوت الانتصار `sound.playVictory()` ومحرك ألعاب الكانفاس `confetti.burst()`.
3. **عداد مشية المزارع والتحميل المحوري (Loaded Carries Tracker):**
   * تسجيل أوزان ومسافات الـ Farmer's Walk والـ Zercher لتوثيق زيادة التجذير الأرضي.

### المرحلة الثالثة: المحتوى التفاعلي ووضع رمضان (Phase 3)
1. **دليل الوجبات الاقتصادية مع زر التحميل الفوري:**
   * كروت وصفات الأكلات المصرية وزر سحري: `[ ⚡ أضف هذه الوجبة لحصص اليوم ]` يغذي العداد بنقرة واحدة.
2. **مفتاح وضع رمضان (Ramadan Mode Switcher):**
   * تفعيل جدول المواعيد والوجبات الأربع لنافذة الصيام خلال شهر فبراير ومارس 2027.

## ٦. مصفوفة إدارة المخاطر وتأكيد الحماية (Risk Mitigation & Safety Gating)

* **خطر فقدان بيانات الـ 180 يوم القديمة:** محمي 100% عبر دمج البيانات الجديدة بشكل متوافق رجعياً (Non-destructive merge in `loadData()`).
* **خطر بطء الواجهة:** العمل معتمد كلياً على DOM النقي وأحداث خفيفة معزولة بدون أي رندر دوري ثقيل.
* **بوابة الموافقة الصريحة:** **لن يتم تعديل أو حفظ سطر كود واحد في ملفات الموقع الأصلية حتى يصدر أمر صريح ومباشر من عمر بالموافقة على خطة التنفيذ.**
